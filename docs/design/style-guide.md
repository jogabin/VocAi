# 화면 규칙

상태: 확인 대기
근거: 화면 CSS(`frontend/src/assets/voc.css`, `frontend/src/App.vue`의 상단 막대, 화면별 `<style>`)에 적용된 값을 그대로 옮겼습니다. 사람이 읽고 확인한 것은 아닙니다.

> 여러 화면이 같이 쓰는 화면 규칙(색, 글자, 간격, 부품)입니다. 값의 원본은 `voc.css` 맨 위 `:root`에 있고, 이 문서는 그 값에 이름과 쓰임을 붙인 것입니다.  
> 화면 구성과 동작은 정하지 않습니다. 구성은 각 화면의 `.vue` 파일이, 동작은 [아키텍처](../architecture/architecture.md)와 [요건](../requirements/requirements.md)이 정합니다.  
> 적용한 화면의 실제 모양은 [screens/](screens/)에 있습니다(가상 데이터).

## 1. 방향

옅은 회색 바탕 위에 흰 둥근 판을 놓고, 판 안은 선 없이 여백으로 나눕니다. 강조는 파랑 하나로 하고, 그림자와 그러데이션은 쓰지 않습니다.  
이 방향을 고른 이유와 같이 검토한 다른 안은 [ADR-012](../adr/ADR-012-ui-restyle.md)에 있습니다.

## 2. 한눈에 보기

| 무엇 | 값 |
|---|---|
| 바탕 | 옅은 회색 `#EDF1F3` 위에 흰 판 |
| 모서리 | 판 16px, 버튼·입력 11px, 배지·칩 9px |
| 판 사이 간격 | 10px |
| 강조색 | 파랑 `#1B64DA`, 옅은 파랑 `#E8F3FF` |
| 글꼴 | Pretendard (못 불러오면 맑은 고딕) |
| 상단 메뉴 | 높이 60px 흰 막대, 알약 모양 메뉴. 선택한 메뉴는 옅은 파랑 바탕에 파랑 굵은 글자 |
| 그림자 | 쓰지 않음 (판은 바탕과의 색 차이로만 구분. 떠 있는 드롭다운 메뉴만 옅은 그림자) |

## 3. 색

값은 `voc.css`의 변수입니다. 글자색은 흰 바탕에서 4.5:1 이상이 되게 잡았습니다(WCAG 1.4.3).

| 변수 | 값 | 쓰임 |
|---|---|---|
| `--bg` | `#EDF1F3` | 페이지 바탕 |
| `--surface` | `#FFFFFF` | 판 |
| `--surface-2` | `#F9FAFB` | 표 머리, 안내 상자, 마우스를 올린 줄 |
| `--text` | `#191F28` | 제목, 본문 |
| `--text-2` | `#4E5968` | 라벨, 보조 본문 |
| `--text-3` | `#6B7684` | 보조 글자, 날짜, 꼬리표 |
| `--accent` / `--accent-strong` / `--accent-soft` | `#1B64DA` / `#1957C2` / `#E8F3FF` | 주 버튼, 링크, 선택한 줄·메뉴 |
| `--line` | `#F2F4F6` | 판 안의 옅은 구분선, 보조 버튼 바탕 |
| `--line-strong` | `#E1E5EA` | 버튼·선택 상자 테두리 |
| `--line-input` | `#8B95A1` | 입력 칸 테두리 (흰 바탕에서 3.1:1) |
| `--p1` / `--p1-soft` | `#D3202F` / `#FDECEE` | P1 긴급, 오류 문구 |
| `--p2` / `--p2-soft` | `#A35A00` / `#FFF3E0` | P2 높음, 경고 |
| `--p3` / `--p3-soft` | `#8A6500` / `#FFF8DB` | P3 보통 (파랑 강조색과 겹치지 않게 노랑 계열) |
| `--p4` / `--p4-soft` | `#5B6573` / `#F2F4F6` | P4 낮음, 보조 배지 |
| `--ok` / `--ok-soft` | `#0F7B4A` / `#E6F6EE` | 사용, 전송, 처리 완료 |

등급은 색만으로 구분하지 않고 글자("P1긴급" 등)를 함께 보입니다. 밝은 화면만 씁니다.

## 4. 글자

| 쓰임 | 크기 | 굵기 |
|---|---|---|
| 화면 제목 | 21px | 800 |
| 판 제목 | 15px | 700 |
| 본문, 입력 | 14px | 400 |
| 표 안, 보조 | 13px | 400~600 |
| 날짜, 꼬리표 | 12px | 400~700 |

큰 제목은 자간을 -0.03em으로 조입니다.

## 5. 부품

| 부품 | 모양 |
|---|---|
| 판(`.card`) | 흰 바탕, 모서리 16px, 테두리·그림자 없음. 머리 줄(15px 굵게)과 오른쪽 보조 글자 |
| 메뉴 알약 | 높이 36px, 모서리 11px. 선택은 `--accent-soft` 바탕에 `--accent` 글자 |
| 버튼 | 높이 36px, 모서리 11px. 주: 파랑 바탕·흰 글자. 보조: `--line` 바탕·진한 글자(테두리 없음). 작은 버튼은 높이 30px |
| 입력·선택·여러 줄 | 흰 바탕, 1px `--line-input`, 모서리 11px, 높이 36px. 포커스는 파랑 테두리 |
| 표 | 머리는 `--surface-2` 바탕의 회색 12.5px 글자, 줄 사이 1px `--line`, 마지막 줄은 선 없음. 마우스를 올리면 `--surface-2`, 선택한 줄은 `--accent-soft` |
| 보기 바꿈 알약(`.seg`, 판별기준 탭) | 목록 위 알약 여러 개. 선택은 흰 판 바탕에 진한 굵은 글자 |
| 배지 | 바탕+글자(테두리 없음), 12px 굵게, 모서리 9px. 등급 배지도 같은 모양 |
| 건수 박스 | 흰 판 모양, 큰 숫자(26px 800)와 이름·설명. 선택한 박스는 옅은 파랑 바탕과 파랑 숫자. 처리하지 않은 긴급 장애가 있으면 빨강으로 깜빡임 |
| 대화 말풍선 | 고객은 왼쪽 회색, 상담사는 오른쪽 옅은 파랑 |
| 짧은 알림(`.toast`) | 진한 바탕·흰 글자, 모서리 11px |

## 6. 화면 뼈대

| 무엇 | 어떻게 |
|---|---|
| 위쪽 막대 | 높이 60px, 흰 바탕, 아래 1px 선. 왼쪽 마스코트와 제품 이름, 가운데 메뉴 알약, 오른쪽 사용자와 로그아웃 |
| 본문 | 최대 폭 1440px 가운데, 바탕 `--bg`, 바깥 여백 10px, 판 사이 10px |
| 로그인 | 바탕 `--bg`, 가운데 흰 판 400px, 위에 걸친 마스코트 |
| 좁은 화면 | 1100px 아래에서 두 칸 배치를 한 칸으로 쌓습니다. 시연은 넓은 화면을 기준으로 합니다 |

## 7. 적용 범위와 다루지 않은 것

- 적용한 곳: 로그인, 상담현황, 상담이력등록, 장애 알림 모니터, 장애 상세정보, 개선의견 목록, 판별기준 관리, 사용자관리, 인사정보 관리, 고객정보 관리, 상담데이터 등록, 권한 없음 안내.
- 화면 구성(어떤 정보가 어디에 있는지)과 동작(무엇을 누르면 어떻게 되는지)은 이 규칙이 바꾸지 않았습니다. 화면 파일의 `<script>`와 `<template>`은 적용 전과 같습니다.
- 목록과 상세를 한 화면에 나란히 두는 3분할 구성은 검토만 하고 적용하지 않았습니다([ADR-012](../adr/ADR-012-ui-restyle.md)).
- 모바일 화면은 범위 밖입니다.
