# 3. 장애처리

상태: 확인 대기  
확인: 정리한 사람 (2026-10-27) · 팀 (2026-10-27. 팀 검토 전이라, 노션 사본의 팀 의견이 오면 옮기고 확인 대기로 되돌려 다시 확인받음)   · 10/27 v2(VocAi) 비교 보강 반영, 팀이 「알아서 판단」으로 맡김 (사람이 읽고 확인한 것은 아님, 확인 대기)
팀 검토 사본: 없음

> 이 문서는 팀이 정한 요건 기준선이라 제출 구현(VocAi)과 다른 곳이 있을 수 있습니다. 이 탭의 요건마다 구현 여부와 근거는 [요건 대비 구현 현황](../vocai-status.md#4-3-탭-3-장애처리)에 있습니다.

> 사용자, 탭 목록, 공통 요건은 [requirements.md](../requirements.md)에 있습니다.  
> 아키텍처, 디자인, 스펙은 여기서 정한 요건을 다시 정하지 않습니다.  
> 고쳐야 하면 요건정리로 되돌려 보냅니다.

## 이 탭은

- 누가 쓰나: IT 담당자
- 무엇을 하려고 쓰나: 자기에게 온 알림과 IT에 넘어온 장애를 보고, 장애 상세에서 AI 판단 결과와 근거를 확인한 뒤 처리 상태와 결과(확정한 원인 포함)를 등록합니다. AI가 오탐으로 판별한 장애를 바로잡습니다.  
  상담사관리자가 탭 2(장애승인)에서 승인한 P2·P3와, 승인 없이 바로 알린 P1이 이 탭으로 넘어옵니다.

번호 3-01~3-07은 10/25까지 있던 옛 탭 3(알림승인)의 번호라 다시 쓰지 않고, 3-08부터 매깁니다(requirements.md 정한 것 47).
