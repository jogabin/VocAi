# 4. 판별기준관리

상태: 확인 대기  
확인: 정리한 사람 (2026-10-24) · 팀 (2026-10-24. 팀 검토 전이라, 노션 사본의 팀 의견이 오면 옮기고 확인 대기로 되돌려 다시 확인받음)   · 10/27 v2(VocAi) 비교 보강 반영, 팀이 「알아서 판단」으로 맡김 (사람이 읽고 확인한 것은 아님, 확인 대기)
팀 검토 사본: 없음 (공유용 노션 사본: 「요건정의-요건정리」의 「4. 판별기준관리」, 검토 전이라 원본은 이 파일)

> 이 문서는 팀이 정한 요건 기준선이라 제출 구현(VocAi)과 다른 곳이 있을 수 있습니다. 이 탭의 요건마다 구현 여부와 근거는 [요건 대비 구현 현황](../vocai-status.md#4-4-탭-4-판별기준관리)에 있습니다.

> 사용자, 탭 목록, 공통 요건은 [requirements.md](../requirements.md)에 있습니다.  
> 아키텍처, 디자인, 스펙은 여기서 정한 요건을 다시 정하지 않습니다.  
> 고쳐야 하면 요건정리로 되돌려 보냅니다.

## 이 탭은

- 누가 쓰나: 관리자
- 무엇을 하려고 쓰나: AI가 장애 등급과 오탐을 판단할 때 쓰는 기준과 판단 예시를 보고 고칩니다. 제품 AI가 판단에 쓸 LLM을 고릅니다.
