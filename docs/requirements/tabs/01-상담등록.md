# 1. 상담등록

상태: 확인 대기  
확인: 정리한 사람 (2026-10-24. 범위 변경에 맞춰 추천대로 고침, 2026-10-25) · 팀 (2026-10-24. 범위 변경으로 고친 것까지 다시 확인함 (2026-10-25). 팀 검토 전이라, 노션 사본의 팀 의견이 오면 옮기고 확인 대기로 되돌려 다시 확인받음) · 범위 변경에 맞춰 고침, 다시 확인 팀, 2026-10-27   · 10/27 v2(VocAi) 비교 보강 반영, 팀이 「알아서 판단」으로 맡김 (사람이 읽고 확인한 것은 아님, 확인 대기)
팀 검토 사본: 없음 (공유용 노션 사본: 1. 상담등록, 검토 전이라 원본은 이 파일)

> 이 문서는 팀이 정한 요건 기준선이라 제출 구현(VocAi)과 다른 곳이 있을 수 있습니다. 이 탭의 요건마다 구현 여부와 근거는 [요건 대비 구현 현황](../vocai-status.md#4-1-탭-1-상담등록)에 있습니다.

> 사용자, 탭 목록, 공통 요건은 [requirements.md](../requirements.md)에 있습니다.  
> 아키텍처, 디자인, 스펙은 여기서 정한 요건을 다시 정하지 않습니다.  
> 고쳐야 하면 요건정리로 되돌려 보냅니다.

## 이 탭은

- 누가 쓰나: 상담사
- 무엇을 하려고 쓰나: 끝난 상담의 이력을 등록하고, AI 판단이 어디까지 진행됐는지 봅니다.  
  같은 장애로 다시 문의가 오면 묶인 장애의 처리 상태와 회신을 보고, 고객에게 안내한 기록을 남깁니다(requirements.md 정한 것 43).  
  판단 근거와 과거 사례 같은 자세한 내용은 장애승인(탭 2)과 장애처리(탭 3)의 장애 상세에서 봅니다.
