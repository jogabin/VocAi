## 이 탭은

- 누가 쓰나: 상담사관리자
- 무엇을 하려고 쓰나: 모든 장애를 급한 것부터 보고, 장애 하나의 상세에서 AI 판단 결과와 근거를 봅니다.  
  AI가 P2·P3로 본 장애를 확인하고, 등급과 알림 내용을 고쳐 승인하면 IT 담당자에게 알립니다. 반려하면 알리지 않습니다(2-12~2-18). 언제든 이유를 적고 등급을 고칩니다(2-19).  
  목록은 승인 대기, 처리한 것, 자동 처리된 P1, 전체로 나눠 보고, 등록 날짜와 처리 날짜로 정렬합니다(2-22, 2-23).  
  승인한 장애의 처리는 IT 담당자가 탭 3(장애처리)에서 하고, 재문의 때 고객 안내는 상담사가 탭 1(상담등록)에서 합니다(requirements.md 정한 것 42·43).
