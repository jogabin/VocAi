# 지킬 것

이 저장소는 팀이 함께 쓰고 대회에 그대로 제출합니다.  
그래서 아래 내용은 코드, 문서, 테스트 데이터 어디에도 넣지 않습니다.

- 실제 고객 정보와 실제 상담 내용.  
  테스트 데이터는 모두 가상으로 만듭니다.
- 실제 장애 사례, 사내 시스템 이름, 사내 업무 절차.  
  필요하면 "무엇이 막혔나, 고객 영향, 급한 정도"만 남긴 일반적인 유형으로 바꿔서 씁니다.
- 근거 없는 수치.  
  숫자를 쓸 때는 어디서 나온 숫자인지 같이 적습니다.
- API 키와 비밀번호.  
  AI 기능은 각자 개인 API 키를 쓰고, 키는 `.env`에만 둡니다.  
  `.env`는 git에 올리지 않습니다.

파일을 지우거나 크게 바꾸기 전에는 먼저 무엇을 바꿀지 말하고 확인을 받습니다.
